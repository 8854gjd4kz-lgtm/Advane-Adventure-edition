# Advanced Adventure Edition

Mobile 3D single-player open-world action RPG prototype.

## Current build
- 10 interchangeable classes
- 20 skills per class (200 total)
- 140 main creatures/NPCs
- 40 peaceful creatures
- 18 bosses
- Connected multi-biome world with no area loading screens
- Level progression through 100
- XP, gold, loot, boss progression, and browser save data
- iPhone touch movement and combat controls
